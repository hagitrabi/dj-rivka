# DJ Rivka · אתר

דף נחיתה לרבקה ניאזוב, DJ Rivka: דיג'יית, מנחה ומפיקה לבת מצווה ולאירועי נשים.

## הקבצים
- `dj-rivka.html`: דף הבית. `index.html` מפנה אליו.
- `articles.html`, `article.html`, `gallery.html`: הדפים הפנימיים. הם נבנים מדף הבית עם `node build-pages.js`, כך שההדר, הפוטר והעיצוב זהים.
- `articles-data.js`: כל המאמרים. מוסיפים מאמר בבלוק חדש.
- `edits.js` + `edits-apply.js`: השינויים שנשמרו בעורך הוויזואלי.
- `public/`: תמונות, הלוגו וסרטוני הגלריה.

## צפייה מקומית
פותחים את `dj-rivka.html` בדפדפן, או מריצים שרת סטטי מהתיקייה.

אפיון, עיצוב ופיתוח: חגית רבי
